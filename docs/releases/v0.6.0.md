## What's new

- **Calculated fields.** A new field type with a formula, for example `@base + skill`. The sheet shows the result, the form shows nothing, and nothing is saved on World Anvil. Names mean the value of that number field (in a list: of the same entry). `@name` means the number field whose label is the text in another field, so each skill in a list can use a different attribute. The Twig is split into short lines so the World Anvil filter keeps it.
- **Dice rolls.** A number or calculated field can write a `[roll:…]` code in the sheet, for example `[roll:2d20<VALUE|VALUE]`. `VALUE` becomes the field's value or the calculated result. How to write rolls: [dice roller documentation](https://dice-roller.github.io/documentation/).
- **New theme: Minimal (light/dark).** It keeps World Anvil's own colors and only adds the card header, borders and stripes with `--light` and `--dark`, so the sheet follows the site's light and dark switch.
- **Sheet settings.** Sheet name, theme, fonts, custom CSS and the project folder moved into a floating panel (top bar button), so the sidebar only holds the selected element. The path bar (Sheet › Row › Col …) now sits above the sheet.
- **Tables.** Right-click adds rows above or below and columns left or right. Table cells can have a width in % or px and a height; drag the bottom edge of a row to change it (double-click: automatic).
- **Numbers while resizing.** A badge shows the value while you drag a col handle (`4/12`) or a table cell handle (`30%`, `240px`).
- **Checker.** A comma inside brackets in `style.css`, like `rgba(…)` or `linear-gradient(…)`, is now an error, because World Anvil's filter breaks it. Use hex colors; `#80808040` is see-through grey. Gradients belong in `approved.css`.
- **Fixes.** Empty list entries stay hidden even when the entry has a dropdown (the form always sends its first option). The ☰ list mark no longer covers the value in narrow table cells.
