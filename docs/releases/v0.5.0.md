## What's new

The first public release of the WA Sheet Generator: design World Anvil character sheets and stat blocks by drag and drop, and export the five files World Anvil needs.

- **Visual editor.** Drag rows, cols, cards, tables, lists, texts, images and fields into the sheet. Double-click to edit texts and labels, right-click for more, undo and redo everything.
- **All World Anvil field types.** Text, number, text area, checkbox, dropdown, text with suggestions and WA image ID, with labels, placeholders and descriptions.
- **Tables made for sheets.** A field dropped into a cell puts its label in a header cell and its input next to it, or all labels on top in a header row, for skill and weapon tables. Column widths are set by dragging the header cells.
- **Lists.** Repeat a row, card or table row up to entry 199. It is exported once inside a Twig loop, and the fields become `weapon_001`, `weapon_002` and so on. Long lists can be split over several cards (1–20, 21–40, …). Preset values give every entry its own text, for example fixed skill names. Empty entries are hidden on the sheet.
- **Formatting without code.** Alignment, bold, italic, underline, colors, sizes, fonts, borders, corners, backgrounds and bullet styles. Everything goes into CSS classes, so the look can still be changed in the CSS later.
- **Nine themes.** Cozy Fantasy, Elegant Medieval, Druid Grove, Steampunk, Horror, Sci-Fi Space, Sci-Fi Cyberpunk, Clean Modern and Clean Modern (dark), with striped rows. They also hold up in World Anvil's dark mode.
- **Fonts.** A library of fonts used on World Anvil sheets, added with one click, or your own font links.
- **Previews.** The Sheet and Form views show the exported files themselves, filled with sample data, with the same Bootstrap version as World Anvil.
- **World Anvil's rules built in.** The checker knows the CSS filter (no `);` or `) {`, no quotes, no `%` inside brackets, one font per `font-family`, no class names starting with `sh` or `py`, no filtered words) and stops the export with a clear list of problems.
- **Nothing gets lost.** Unsaved work is kept automatically and offered again after a reload or a crash. Recent sheets are one click away.
- **Windows, Linux and macOS.** One program file per system, nothing to install, no account; internet only to load web fonts.
